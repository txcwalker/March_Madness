Format

Each article is one Markdown file in content/articles/, with a frontmatter block at the top (title, date, summary) followed by the article body in standard Markdown -- headings, paragraphs, lists, tables, links, all supported.

The slug used in the page's URL is the filename itself (example-article.md becomes articles/example-article.html), so name files something stable and readable.

Re-run python scripts/build_site.py after adding or editing an article to regenerate the site.
